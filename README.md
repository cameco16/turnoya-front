# TurnoYa: maquetación inicial

Maquetación en HTML y CSS del prototipo de TurnoYa, una plataforma web de agendamiento de citas para barberías de barrio. Proyecto académico del curso Análisis y Diseño de Sistemas (Actividad 2).

Solo incluye interfaz y navegación. Los datos son de ejemplo y no se guarda información.

- **Flujo del cliente:** `index.html`
- **Panel de la barbería:** `admin/login.html`
- **Guía de estilos:** `guia-estilos.html`
